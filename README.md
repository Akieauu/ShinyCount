# Wish Shiny Counter
 
> A simple desktop app to track shiny Pokémon resets.
 
## Installation
 
```bash
pip install pillow pynput
python shiny_counter.py
```
 
## Keyboard Shortcuts
 
| Key | Action |
|-----|--------|
| `A` | Increment counter |
| `E` | Decrement counter |
| `R` | Reset to 0 |
 
> Shortcuts work globally, even when the window is not focused.
